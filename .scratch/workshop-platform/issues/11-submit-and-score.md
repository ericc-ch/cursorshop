# 11 — Submit fields and score dimensions

Type: grilling

Question: What do participants submit, and what do judges score 1–10?

Answer: **Submit:** GitHub repo, deployed URL, PRD and RFC as Markdown strings, and screenshots (R2). **Score dimensions:** PRD, RFC, App (1–10 each). “App” matches slide 35 (screenshots + deployed URL). Leaderboard averages those three across judges; tiebreak stronger App then earlier submission.
