# 22 — Screenshot constraints

Type: grilling

Question: What screenshot uploads does a submission require?

Answer: Require **1–3 screenshots**. Each file must be **smaller than 1 MB (1,000,000 bytes)** and have MIME type **JPEG, PNG, or WebP**. Create a submission with one bounded multipart request containing its fields and all screenshots. After creation, replace or remove one screenshot slot per request using the submission edit token.
