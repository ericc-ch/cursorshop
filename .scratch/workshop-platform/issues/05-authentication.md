# 05 — Authentication

Type: grilling

Question: Is Better Auth required for the cursorshop workshop platform?

Answer: **No — skip auth.** Source of truth is `docs/workshop_slides.md` (not `docs/plan.md`). cursorshop is submit → judge score → leaderboard for a ~3 hour build; slides never require login, accounts, or roles. Slide 08 lists submissions and scoring; slide 35 has judges scoring independently and the platform averaging — no identity system. (Slide 28’s “auth” is only an example of a change that might need heavier review, not a product requirement.) Better Auth is out of scope.
