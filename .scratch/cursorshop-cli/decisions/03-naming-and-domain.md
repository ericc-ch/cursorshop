# 03 — Naming and domain

Type: grilling

Question: What is the canonical project name and public hostname?

Answer: The project, npm package, and CLI binary are **`cursorshop`** in all-lowercase everywhere. The public site is **`cursorshop.ericc.ch`**. The public API is **`api.cursorshop.ericc.ch`**. The CLI defaults to `https://api.cursorshop.ericc.ch`. Domain terms such as Room and Submission stay as defined in `CONTEXT.md`; the product is `cursorshop`.
